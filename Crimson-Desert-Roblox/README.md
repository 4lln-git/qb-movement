# Crimson Desert — Roblox

Working folder for the **Crimson Desert** Roblox game. Kept separate from the
QB Movement planning vault — the two projects share this repo but nothing else.

## What's here
```
Crimson-Desert-Roblox/
├── UI/          Interface mockups & design system
│   └── index.html   ← the UI bible (10 screens: HUD, inventory, map, etc.)
├── src/         Game code (Lua/Luau) — scripts, modules
└── assets/      Art, audio, and other game assets
```

## UI
Open `UI/index.html` in a browser to view the full interface design system —
every screen, component, and style token for the game's UI.
