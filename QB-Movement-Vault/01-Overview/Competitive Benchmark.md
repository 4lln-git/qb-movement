# Competitive Benchmark

## What we're learning from each

| Product | What it does well | What we take |
|---|---|---|
| **[House of Athlete](https://houseofathlete.com)** | Premium brand, athlete media, membership feel | Visual bar, membership framing, mobile-first |
| **Hudl / Hudl Studio** | Film + team management, the standard in football | [[Film Room]] timestamped feedback, team rosters |
| **Just Play / CoachTube** | Digital playbooks, install & quiz players | [[Digital Playbook]] drawing + assignment + quizzing |
| **Whoop / Strava** | Streaks, progress, social leaderboards | [[Gamification]] loop, daily-habit design |
| **Duolingo** | RPG-ish progression, streaks, "one more lesson" | [[QB Skill Tree]] levels, badges, daily challenge |
| **MaxPreps / NCSA** | Recruiting profiles & exposure | Recruiting Hub profile shape |
| **OnForm / Dartfish** | Video coaching + slow-mo annotation | [[Throw Analysis AI]] + frame-by-frame review |
| **TeamSnap / Mindbody** | Scheduling, attendance, payments | Booking, camps, [[Coach Dashboard]] ops |

## The gap we fill
No single product combines **daily training content + drawable playbook + RPG progression + AI throw analysis + coach business tools** for the **quarterback** niche specifically. That focused bundle is the wedge.

## Positioning map (mental model)
- **Generic fitness apps** → broad, not football-smart.
- **Hudl** → film/team ops, not daily player development or gamification.
- **Skills trainers' link-in-bio + Weebly** → what QB Movement is escaping.
- **QB Movement** → the *daily QB development OS* for the niche.
