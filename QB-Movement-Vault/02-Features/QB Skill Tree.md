# QB Skill Tree 🎮

> [!quote] The pitch
> Instead of boring percentages — imagine **RPG progression.** Players level up, earn badges, unlock drills.

## The attributes
Five core ratings, shown as progress bars (Madden-style):

```
Throw Power      ████████░░  80
Accuracy         ██████░░░░  60
Pocket Presence  ███████░░░  70
Leadership       █████████░  90
Football IQ      █████░░░░░  50
```

## How ratings change (the important part)
Ratings must be **earned through real activity**, not vanity. Map inputs → attributes:

| Attribute | Driven by |
|---|---|
| Throw Power | Velocity/distance from [[Feature Catalog\|Digital Combine]], strength workouts logged |
| Accuracy | Throwing program completion, target drills, AI throw scores ([[Throw Analysis AI]]) |
| Pocket Presence | Footwork drills, mobility sessions, ladder work |
| Leadership | Streaks, team participation, camp attendance, helping others |
| Football IQ | [[Digital Playbook]] Read & React quizzes, QB IQ quizzes, film breakdowns |

## Progression mechanics
- **XP** from completing drills, programs, challenges, quizzes, journal entries.
- **Levels** (overall QB level) unlock new content/drills.
- **Badges** for milestones ("100-day streak", "Cover-2 Master", "1000 throws").
- **Unlocks**: higher levels open advanced drills, exclusive videos, playbook templates.

> [!tip] Make it honest
> Tie attributes to verifiable inputs (combine numbers, completed sessions, quiz scores) so the skill tree reflects *actual development*, not just app usage. That's what makes it credible to coaches and recruiters.

## Why it matters
This is the **retention engine**. Combined with [[Gamification]] (streaks, challenges, leaderboards), it turns training into a game players *want* to open daily — the core of the subscription thesis in [[Vision & Positioning]].

## Where it shows up
- Player home screen (hero element).
- [[Parent Dashboard]] (progress over time).
- Recruiting Hub profile (credible, data-backed ratings).
- [[Coach Dashboard]] (roster-wide view of who's improving).
